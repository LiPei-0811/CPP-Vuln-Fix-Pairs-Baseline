# AI辅助C/C++漏洞挖掘方向开源代码清单

检索日期：2026-09-16

定位：面向“真实C/C++漏洞的证据增强检测、补丁感知检索、CPG切片与受控执行验证”。本清单优先收录论文官方仓库、数据集官方仓库及可直接支撑实验的基础工具。

说明：已对下列71个与你课题高度相关的GitHub地址进行可访问性检查，均返回成功；“公开仓库”不等于许可证允许任意再分发，正式复用前仍需逐项检查LICENSE、数据许可和模型许可。“所有”无法作绝对穷举，本清单通过两个持续更新的索引仓库补充后续新增项目。

## 一、最推荐的落地组合

1. 数据与评测：PrimeVul + CVEfixes + Vul-RAG/LinuxVul。
2. Direct基线：Qwen2.5-Coder + CodeBERT + LineVul。
3. 结构化上下文：Joern + LLMxCPG。
4. 补丁证据：Vul-RAG的patch diff + GumTree AST diff。
5. 静态证据：CodeQL或Semgrep。
6. 受控执行：SEC-bench任务规范；小规模吸收DrillAgent执行反馈；底层可选AFL++/Magma。

## 四、不建议当前阶段直接完整复现

- Cochise、PentestGPT：环境和安全边界复杂，偏离C/C++源代码检测主线。

- 完整Linux内核PoC复现：需要QEMU/KVM、内核构建和调试基础设施，建议后置。
- 大规模OSS-Fuzz集群：先以单项目Docker/ASan验证替代。

## 六、与当前项目的直接对应关系

- `datasets/primevul_test*.jsonl`：继续来自PrimeVul。
- 需要补丁差异和CWE较完整的数据：优先引入Vul-RAG/LinuxVul与CVEfixes。
- 需要行级或语句级定位基线：LineVul、LineVD。
- 需要CPG切片：Joern、LLMxCPG。
- 需要规则/数据流证据：CodeQL、IRIS、Semgrep。
- 需要执行反馈：SEC-bench、DrillAgent；底层使用ASan/UBSan、AFL++或Magma。
- 当前最可行的论文最小实现：PrimeVul paired检测 + Vul-RAG补丁知识检索 + Joern切片 + Qwen判定 + 小规模ASan验证。
