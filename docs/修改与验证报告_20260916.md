# 面向真实C/C++漏洞—修复对的直接检测与修复敏感性基线实验修改与验证报告

最后检查日期：2026-09-16

## 一、已修改内容

1. 删除Direct提示词中的具体`CWE-787`示例，避免类别锚定。
2. 增加JSON语法与预测Schema的双重校验。
3. 增加模型、输入数据、提示词和Schema运行签名，阻止错误断点续跑。
4. 非resume推理改为覆盖输出，避免重复追加预测。
5. 评估程序默认要求预测完整覆盖全部gold，并拒绝重复、缺失和额外ID。
6. Top-k无真实行标注时返回`null/N/A`。
7. 增加patched误报、benign误报和四类pair outcome。
8. CWE只在gold非空的真实漏洞样本上进行探索性统计。
9. 抽样改为固定seed随机无放回，并输出明确sampling_method。
10. 普通良性样本排除精确代码、空白规范化代码和相同项目提交。
11. 为100个漏洞—修复对增加补丁差异行证据，但不冒充漏洞行gold。
12. 增加CodeBERT训练—评测泄漏检查和统一预测输出。
13. 增加一键运行脚本、配置示例和完整中文README。
14. 增加71个相关公开仓库的开源代码清单。
15. 项目目录更名为`C_CPP漏洞修复对直接检测与修复敏感性基线实验_20260916`。
16. 普通良性函数的有效gold CWE设为`null`，原始字段单独保存在`source_cwe`。
17. Smoke Test改为同一`pair_id`下的vulnerable/patched函数对。
18. 明确配置VS Code使用`primevul-exp`环境，并整理`docs`目录与`.gitignore`。
19. 运行签名加入gold规范哈希、全部推理参数和Schema 1.1，评估器会拒绝旧gold、旧提示词和混合签名。
20. 区分可恢复JSON与严格JSON；代码围栏不再计入严格JSON有效率。
21. 评估器会独立复核规范化预测Schema，无效输出在CWE和定位中不再获得隐性收益。
22. 一键脚本改为按传入配置解析`output_dir`，并把同一配置传给全部检查脚本。
23. CodeBERT改用独立验证集选择最佳epoch，不再使用最终测试集调参。
24. 数据读取改为非法JSON、非法标签和重复规范化代码显式失败。
25. 增加8项自动化回归测试，并兼容Windows PowerShell常见的UTF-8 BOM配置文件。
26. 增加6个本地数据文件的大小、记录数和SHA256清单；来源Commit、下载日期和许可结论仍待人工补录。
27. 代码近重复检查改为轻量C/C++词法规范化，避免字符串字面量空白被误删或不同词法单元被错误合并。
